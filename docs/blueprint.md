# **App Name**: PeopleOps Central

## Core Features:

- Employee Database: Manage employee data, including personal information, job details, and contact information.
- Warning Letter Management: Create, track, and manage employee warning letters, including different types (SP1/SP2/SP3/Teguran) and their statuses.
- Reporting Center: Generate reports on employee data, warning letters, and turnover rates, with options to filter and download in various formats.
- Employee Profile: View and manage detailed profiles for each employee, including personal information, job history, documents, and warning history.
- Smart reminders: Generative AI tool providing reminders based on contract expiry and warning letter expiration. A tool will incorporate relevant database values such as warning status or contract dates when it appears important to do so.
- Dashboard Summary: Provides a central point of insight and quick actions for HR related processes.

## Style Guidelines:

- Primary color: Indigo (#4F46E5) for a modern, strong accent color on interactive elements. It fits well with a Gen Z-focused approach and the theme of an efficient, approachable app.
- Background color: Dark gray (#121212) for a clean, minimalist dark theme.
- Accent color: Light blue (#7DD3FC) as a contrast to the indigo and dark background to ensure elements such as call to actions really stand out.
- Body and headline font: 'Inter' (sans-serif) for a clean, professional, and modern look.
- Use functional emojis for employee status: ✅ for Active, 📄 for Contract, 🚶 for Resign/Inactive, ⚠️ for Under Warning.
- Card-based layout for summaries and quick actions on the dashboard. Use modern, responsive tables for data display.
- Smooth transitions and visual feedback for user actions, such as adding an employee or issuing a warning. Ensure feedback messages are clear and non-intrusive.
